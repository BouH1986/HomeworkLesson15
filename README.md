Коллекции HashSet и HashMap. Урок 15

Вашей задачей будет написание сервиса услуг доставки товаров по миру.

Адрес доставки будет задаваться двумя данными: страна (country) и город (city). Создайте для этих целей класс Address.

В main создайте несколько адресов и мапу costPerAddress, в которой ключом будет адрес, 
а значением — цена доставки 1 кг груза. Заполните мапу созданными адресами и произвольными значениями цен доставки по этим адресам.
